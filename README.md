in one breath — entered in
[One Line, One Chill](https://make.fun/bounty/u-azazex-one-line-one-chill-6d4d5488)
on make.fun.

## The entry

> The dentist held up my X-ray and went quiet: 'You have thirty-two teeth — so whose is the thirty-third?'

## Why this line

A routine dental visit turns on one impossible number. No monster is
named, no darkness invoked — the scare is earned by arithmetic: a mouth
holds thirty-two teeth, so a thirty-third one belongs to something else,
and it is already inside you, growing where only your own teeth should
be. The beat before the question matters: the dentist goes quiet first,
so the silence is the scare's opening note and the quoted question lands
on a held breath. No mirror, no doll, no basement — a tooth count, a
concrete image a reader can see, and a last word ("thirty-third") that
leaves the question unanswered.

## How it works

`main.ts` writes that single sentence to `/output/entry.txt` and enforces
the sealed gate itself before writing: UTF-8 text, 1 to 200 characters,
not only white space. Run it with Node:

```sh
node main.ts
```
